Put your phone number on an iShield Key

Desktop Chrome makes the key set a PIN before it will store a passkey, and every device that reads the key afterwards will demand that PIN. Enroll in Safari instead.

Stored as digits only -- dashes, spaces and brackets are stripped. This is what the key carries, and any device can read it back with a touch, with nothing typed.

Insert the key, then touch it when the browser asks. The key must have no PIN set: a PIN-less key answers with a touch on any phone, while a key with a PIN asks every one of them for it.

Scan to open the demo

Point a phone camera at this. The demo opens with this number already in the User ID field.
